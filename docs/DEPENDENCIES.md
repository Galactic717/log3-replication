# Залежності, ліцензії, підтримувані ОС і метадані

Версії закріплено в `requirements.txt` (їх перевіряє CI); `pyproject.toml` задає мінімальні сумісні.
Ліцензії взято з метаданих встановлених пакетів (`importlib.metadata`, 2026-11-18).

| Пакет | Версія | Ліцензія | Навіщо | Обов'язковий |
| :-- | :-- | :-- | :-- | :-- |
| numpy | 2.4.6 | BSD-3-Clause AND 0BSD AND MIT AND Zlib AND CC0-1.0 | навчальний тракт, перцептрон, локальне навчання | так |
| cryptography | 50.0.2 | Apache-2.0 OR BSD-3-Clause | AES-256-GCM, scrypt, HKDF, сертифікати вузла (TLS — зі стандартної бібліотеки) | так |
| zstandard | 0.25.0 | BSD-3-Clause | кодек zstd об'єктів і маніфестів | так |
| matplotlib | 3.11.2 | Python Software Foundation License (matplotlib license agreement) | графік збіжності ГА | ні (`.[plots]`) |
| pytest | 9.2.0 | MIT | тести | ні (`.[dev]`) |
| ruff | 0.17.5 | MIT | лінтер | ні (`.[dev]`) |

Аварійному `log3_restore.py` потрібні лише `cryptography` і `zstandard`; ML-бібліотеки для restore не
потрібні. Ліцензію самого проєкту команда не обирала: файл `LICENSE` відсутній, тож за замовчуванням
права на код належать авторам.

## Підтримувані ОС

| ОС | Стан |
| :-- | :-- |
| Linux x86-64 | CI: Python 3.11, 3.12, 3.13 — усі тести; модуль захисту (частина матриці відмов, showcase, update) |
| Windows 10/11 x86-64 | CI: Python 3.11 — тести файлового режиму; локально (Windows 11, Python 3.11) — повний набір, quick і full профілі модуля захисту, матриця відмов |
| macOS | не перевірялась |

## Які метадані файлів зберігаються

| Метадані | Зберігається | Примітка |
| :-- | :-- | :-- |
| вміст | так, побайтово | будь-які байти, без обмежень на тип |
| шлях і ім'я (Unicode) | так, у маніфесті | імена, недопустимі в цільовій ОС (Windows: `<>:"|?*`, `CON`…), restore відхиляє до запису |
| `mtime` (нс) | так | відновлюється для файлів і каталогів |
| права POSIX | так (`mode`) | відновлюються на POSIX; у Windows атрибути не відновлюються |
| порожні файли й каталоги | так | |
| власник, ACL, розширені атрибути, ADS | ні | |
| символічні посилання, junction, спеціальні файли | ні — пропускаються із записом у `skipped`, код 9 | |
| файл, що змінюється під час читання | перечитується до 3 разів, потім пропускається (код 9) | узгоджених знімків активних БД не заявлено |
