# Таблиця 4. Стиснення до і після шифрування

Середовище: пакет викладача (`materials/`: team_config.json, replication.py, session.csv).

Увесь сеанс (1200 записів) однією реплікою. Шифротекст AES-CTR статистично схожий на випадкові байти (256 різних значень із 256, частоти рівні), тож Гаффман дає ≈ 8 біт на байт плюс таблицю: стискати треба до шифрування.

| Варіант | Байти | Від сирого |
| :-- | :-- | :-- |
| сирі записи | 19200 | 1.0000 |
| Гаффман (payload, без шифрування) | 11920 | 0.6208 |
| стиснути → зашифрувати (репліка LOG3) | 11995 | 0.6247 |
| лише зашифрувати (NO_COMPRESSION) | 19289 | 1.0046 |
| зашифрувати → Гаффман | 19815 | 1.0320 |
| довідково: zlib сирих записів | 10875 | 0.5664 |
| довідково: zlib шифротексту | 19230 | 1.0016 |
