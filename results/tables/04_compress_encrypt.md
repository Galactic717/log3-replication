# Стиснення до і після шифрування

**Середовище: dev-конфіг і dev-модель реплікації (log3/devsim.py) — пакет викладача ще не покладено в materials/. Числа ілюструють методику, не офіційний Q.**

Увесь сеанс (960 записів) однією реплікою. Шифротекст AES-CTR статистично схожий на випадкові байти: частоти байтів рівні, Гаффман дає ≈8 біт на байт плюс таблицю, тому стискати треба до шифрування.

| Варіант | Байти | Від сирого |
| :-- | :-- | :-- |
| сирі записи | 15360 | 1.0000 |
| Гаффман (payload, без шифрування) | 8323 | 0.5419 |
| стиснути → зашифрувати (репліка LOG3) | 8398 | 0.5467 |
| лише зашифрувати (NO_COMPRESSION) | 15449 | 1.0058 |
| зашифрувати → Гаффман | 15974 | 1.0400 |
| довідково: zlib сирих записів | 6774 | 0.4410 |
| довідково: zlib шифротексту | 15385 | 1.0016 |
